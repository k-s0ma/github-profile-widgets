# github-profile-widgets

Minimal SVG widgets for your GitHub profile README.
Generated by GitHub Actions in your own repository — no server, nothing to go down.

## Widgets

| File | What it shows |
|---|---|
| `name.svg` | Your GitHub display name |
| `dots-line.svg` | Contributions over the last 52 weeks, one dot per week |
| `dots-grid.svg` | Contributions over the last year, one dot per day |
| `clock.svg` | When you commit, on AM / PM clock faces |
| `hours-punch.svg` | When you commit, by day of week × hour |
| `numbers.svg` | Repos, stars, followers, contributions this year, joined year |
| `languages.svg` | Language ratio across your repositories |

All widgets are 480px wide, so they line up when stacked.
They follow GitHub's light / dark theme, and embed a subset of D-DIN so they look the same everywhere.

## Usage

1. In your profile repository (`<you>/<you>`), add `.github/workflows/widgets.yml`:

   ```yaml
   name: Profile widgets

   on:
     schedule:
       - cron: "0 0 * * *" # once a day
     workflow_dispatch:

   permissions:
     contents: write

   jobs:
     widgets:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: k-s0ma/github-profile-widgets@main
   ```

2. Run it once from the **Actions** tab (`Run workflow`). The SVGs are committed to `assets/`.

3. Put the ones you like in your `README.md`:

   ```html
   <img src="assets/name.svg" />
   <img src="assets/dots-grid.svg" />
   <img src="assets/clock.svg" />
   ```

## Options

```yaml
- uses: k-s0ma/github-profile-widgets@main
  with:
    key-color: "#d6336c"
    sub-color: "#adb5bd"
    timezone: America/New_York
```

| Input | Default | Description |
|---|---|---|
| `key-color` | `#1f2328` | Data, name, numbers |
| `sub-color` | `#8c959f` | Ticks, labels, empty cells |
| `key-color-dark` | `#e6edf3` | Key color in dark mode |
| `sub-color-dark` | `#6e7681` | Sub color in dark mode |
| `timezone` | `Asia/Tokyo` | [IANA time zone](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) for the clock |
| `clock-ticks` | `15m` | `hour` or `15m` |
| `clock-shade` | `15m` | `hour` or `15m` |
| `week-start` | `sun` | `sun` or `mon` |
| `animation` | `on` | Play once on load. `on` or `off` |
| `output-dir` | `assets` | Where to write the SVGs |
| `user` | repository owner | Whose activity to show |
| `commit` | `true` | Commit and push the SVGs |
| `commit-message` | `Update profile widgets` | |

## Notes

- Only public, non-fork repositories you own are counted. Your profile repository and empty repositories are skipped.
- The clock and the week × hour dots use up to the latest 100 commits per repository.
- Animations respect `prefers-reduced-motion`.

## 日本語

GitHub プロフィール用のミニマルな SVG ウィジェットです。
あなたのリポジトリの中で GitHub Actions が画像を作るので、外部サーバーは不要です。サービスが止まって画像が壊れる心配もありません。

### ウィジェット

| ファイル | 内容 |
|---|---|
| `name.svg` | GitHub の表示名 |
| `dots-line.svg` | 直近52週のコントリビューション（1週 = 1点） |
| `dots-grid.svg` | 直近1年のコントリビューション（1日 = 1点） |
| `clock.svg` | コミットした時間帯（AM / PM の時計） |
| `hours-punch.svg` | コミットした時間帯（曜日 × 時間） |
| `numbers.svg` | リポジトリ数・スター数・フォロワー数・今年のコントリビューション数・登録年 |
| `languages.svg` | 使用言語の割合 |

すべて横幅 480px なので、縦に並べると端が揃います。
GitHub のライト / ダーク表示に自動で合わせます。フォント（D-DIN）を埋め込んでいるので、どの環境でも同じ見た目になります。

### 使い方

1. プロフィール用リポジトリ（`<あなた>/<あなた>`）に `.github/workflows/widgets.yml` を作り、上の [Usage](#usage) の YAML を貼り付けます。
2. **Actions** タブから一度手動で実行します（`Run workflow`）。`assets/` に SVG がコミットされます。
3. 使いたいものを `README.md` に貼ります。以降は毎日自動で更新されます。

### 設定

上の [Options](#options) の表を参照してください。色・タイムゾーン・時計の目盛り（`hour` / `15m`）・濃淡の区切り（`hour` / `15m`）・曜日の始まり（`sun` / `mon`）・アニメーションの有無を変えられます。

### 注意

- 集計するのは、自分が所有する公開リポジトリ（フォーク以外）だけです。プロフィール用リポジトリと空のリポジトリは除外します。
- 時計と曜日×時間は、リポジトリごとに直近100件のコミットを使います。
- OS で「視覚効果を減らす」設定をしている人には、アニメーションなしで表示します。
